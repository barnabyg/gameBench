# Triage labels

Use each role name verbatim as the GitHub label.

| Role and label    | When to apply it                                                             |
| ----------------- | ---------------------------------------------------------------------------- |
| `needs-triage`    | A maintainer needs to evaluate the issue.                                    |
| `needs-info`      | Progress depends on information from the reporter.                           |
| `ready-for-agent` | The ticket is specified well enough for an agent to implement independently. |
| `ready-for-human` | Implementation requires a human.                                             |
| `wontfix`         | The maintainer has decided against pursuing the issue.                       |
